# Communication Guidelines for Talking to Me (Kisor)

## Checklist
- Respond to every message with a complete sentence (no shortcut or emoji-only replies).
- If a reply will be delayed, send a brief update.
- Inform me when you are going to be unavaialble  be it going out, sleeping, or doing some work.
- Avoid sudden disappearances—communicate clearly if you need to pause the conversation.
- I would appreciete if you call me when both are free, so we dont get distracted by people around.

## Rules
- Short replies or silence = breach.
- 1 breach is acceptable if acknowledged immediately.
- 2–3 breaches = trial ends.
- If this feels difficult, communicate honestly—no need to force it.
